# 💰 Personal Finance Dashboard

## 📌 Project Overview
-This is a simple Personal Finance Dashboard built using React.
It helps users to track income, expenses, and view insights.
This is a frontend-only application. All data used in this are
custom sample data.
No backend or database is connected

---

## 🚀 Features

- Dashboard with total income, expenses, and balance
- Transactions page with search and filter
- Insights page with charts
- Dark mode support
- Responsive design

---

## 🛠️ Technologies Used

- React.js
- JavaScript
- Tailwind CSS
- Recharts (for charts)

---

## ⚙️ Setup Instructions

1. Clone the repository
2. Install dependencies (npm install)
3. Run the project (npm run dev)

---

## 📊 Pages

- Dashboard
- Transactions
- Insights

## ✅ Conclusion

This project shows how to build a simple and clean UI for managing personal finance data.
